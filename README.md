Whale Cottage — a cosy hand-drawn spot-the-difference game: study two near-identical cottage scenes side by side and find all 7 differences, with hints, a timer, keyboard play and synthesized sound effects.
## Run it
```sh
node serve.ts
```
then open http://localhost:8080 — or just open game/index.html directly in a desktop browser.
